NOTE: THE PROJECT MUST HAVE AN APPLICATION SPECIFIC FOR BARANGAY RESIDENCE AND ADMINS AND A WEBSITE THAT IS ONLY ACCESSIBLE BY THE ADMINS (Unified Platforms)



Create a full-stack project called “BarangayConnect: Community Request and Announcement System”.



SYSTEM OVERVIEW:

BarangayConnect is a barangay management platform with:

- Admin users who can access BOTH the website dashboard and mobile app

- Resident users who can ONLY access the mobile app

- Residents can submit requests and receive announcements from the barangay officials



IMPORTANT ACCESS RULE:

- Admin can use Website + Mobile App

- Resident/User can ONLY use Mobile App

- Residents must be blocked from accessing the admin website dashboard

- Implement role-based authentication and protected routes
